SEPTEMBER ENGLISH: LEVEL UP — GitHub Pages

1. Откройте архив и извлеките все файлы.
2. Загрузите СОДЕРЖИМОЕ папки в корень репозитория GitHub.
3. Откройте Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root), затем Save.
6. Подождите 1–3 минуты и откройте появившуюся ссылку.

Важно: index.html должен находиться в корне репозитория, а не внутри дополнительной папки.
