# FAMILY FEED — Teacher Guide

**Course:** Gateway to the World B1, Unit 1 material transformed into an interactive 1:1 digital lesson  
**Level:** B1  
**Format:** one student + one tutor  
**Full route:** about 90–120 minutes  
**Core route:** Vocabulary → Reading → Grammar → State/action verbs → Dialogue → Word building → Final mission  
**Extra practice:** Lexi Loop + Glitch Clinic

## Communicative outcome
By the end, the learner can describe family relationships, discuss sharing family photos online, distinguish present simple from present continuous, handle common state verbs, build nouns with common suffixes, and present a short family social-media policy.

## Suggested route
1. **Family Files** — ages/stages; family relations; “Legendary Family”; definition game; family-connected words; personal speaking.
2. **Lexi Loop** — optional retrieval block. Use Recognise → Match → Recall → Use. It can also be homework/revision.
3. **Sharenting** — prediction/discussion → gist → detail → vocabulary in context → critical response.
4. **Present Simple / Present Continuous** — notice → uses → form → time/context clues → question building → tutor interview.
5. **State & action verbs** — guided discovery with *think / be thinking* → classify common state verbs → Celebrity Kids practice. Glitch Clinic is extra.
6. **Messenger Mode** — complete the textbook dialogue, then write and ask five personal questions.
7. **Word Builder** — notice suffixes → identify source word class → form nouns → complete questions → personalise.
8. **Final Mission** — learner presents a 60–90 second “Family Feed Policy”. Do not auto-grade speaking; use the checklist and tutor feedback.

## High-value answer key
- **Legendary Family:** husband; daughter; son; aunt; uncles; sister-in-law; brothers-in-law.
- **Family connected:** single; divorced; only child; partner; one-parent; immediate; extended; twin; relative.
- **Reading title:** option 2.
- **Reading detail:** 1b, 2c, 3a, 4b.
- **Present simple / continuous form:** studies; doesn’t study; does; study; is studying; isn’t studying; is; studying.
- **State/action:** *don’t like, need, think* = state; *are thinking about* = action/process. The listed verbs *love, hate, believe, know, understand, want, care* usually describe states.
- **Celebrity Kids:** hate; post; do you think; want; are playing; know; are watching; understand; need; sell; believe; care.
- **Messenger dialogue:** are / doing; am doing; are / studying; come; visit; make; know; is; is crying; think; are taking; don’t believe.
- **Noun text:** explanation; confidence; adolescence; embarrassment; solution; enjoyment; improvement; independence; connection.
- **Word completion:** improve; independent; confidence; embarrass; differences.

## Feedback and reset
Closed tasks include **Check** plus a Hint/Try again or equivalent where appropriate. Open speaking/writing tasks use prompts, checklists and tutor follow-up instead of false automatic “correct/incorrect” marking.

The top-bar **New student** action clears local lesson data and reloads a clean copy for the next learner.

## Accessibility / devices
The lesson is responsive for desktop, tablet and mobile; mouse/touch interactions have click/tap alternatives; focus styles are visible; the page supports reduced-motion preferences. Speech playback uses the browser’s built-in speech synthesis when available and is an enhancement, not a Core Route dependency.
